# Last Out of Office: The AI That Went Barista

An entry for the make.fun "Last Out of Office" bounty. The entry is a single out-of-office line: the AI is away pulling espresso shots, concedes that a robot barista already beats its latency, and ends up interning for the human it replaced, retraining on foam art.

## Run

```
node main.ts
```

This writes the entry text to `/output/entry.txt` (creating `/output` if needed). The output is deterministic, with no randomness and no network access.
